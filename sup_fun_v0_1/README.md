# SUP FUN — Flutter Prototype v0.1

Рабочий UI-прототип мобильного приложения SUP FUN на Flutter. Версия сделана без backend и внешних пакетов для карты/GPS: данные демонстрационные, карта отрисовывается локально.

## Что реализовано

- Главная
- Карта с демонстрационным маршрутом
- Водоём/событие через карточки
- Сообщество / лента
- Профиль и уровень
- Центральное меню `+`
- Создание заплыва
- Предстартовая проверка
- Экран активного трекинга
- Пауза / продолжение
- Завершение заплыва
- Экран результата и XP
- Детали маршрута
- Маркетплейс
- Light UI на Material 3
- Навигация между основными экранами

## Как запустить

1. Установите Flutter SDK и Android Studio или VS Code.
2. Распакуйте архив.
3. В каталоге проекта выполните:

```bash
flutter pub get
flutter run
```

Если архив содержит только исходники без платформенных каталогов, один раз выполните:

```bash
flutter create .
flutter pub get
flutter run
```

После этого можно запускать на Android-эмуляторе, физическом Android-устройстве или iOS Simulator на macOS.
