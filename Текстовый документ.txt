📱 Мобильное приложение — Flutter + Dart

Язык: Dart
Фреймворк: Flutter

Это мой основной выбор для SUP FUN.

Почему:

один код для iOS + Android;
можно очень точно повторить наш дизайн;
удобно делать сложные анимации;
хорошие возможности для карт;
GPS и background tracking;
offline-хранение;
push-уведомления;
Bluetooth/датчики в будущем;
можно позже сделать поддержку Apple Watch / Wear OS;
один UI-код вместо двух отдельных приложений.

То есть мы создаём один проект:

🗺 Карта

Для SUP FUN карта — один из самых важных компонентов.

Я бы сразу проектировал отдельный модуль:

Map
├── UserLocation
├── Routes
├── Events
├── Waterways
├── Friends
├── Weather
└── Track

Причём трек пользователя должен записываться независимо от интернета.

Например:

GPS
 ↓
Location Service
 ↓
Local Track Storage
 ↓
Background Tracking
 ↓
Internet появился
 ↓
Sync
 ↓
Server

Это намного надёжнее, чем пытаться записывать маршрут непосредственно через сервер.

🚀 Backend

Здесь я бы выбрал:

TypeScript + NestJS

То есть:

Frontend

Flutter
Dart

Backend

NestJS
TypeScript

Это хороший вариант именно для такого проекта, потому что один язык можно использовать в серверной инфраструктуре и части общих инструментов.

🗄 База данных
PostgreSQL + PostGIS

Причём PostGIS очень важен.

Потому что у нас будут:

координаты;
маршруты;
точки старта;
водоёмы;
расстояния;
поиск рядом;
геозоны;
треки.

Например запрос:

Покажи заплывы в радиусе 20 км от меня.

PostGIS для этого подходит гораздо лучше обычной базы.
