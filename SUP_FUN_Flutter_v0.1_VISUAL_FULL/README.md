# SUP FUN — Flutter Prototype v0.1 VISUAL FULL

Это исправленная сборка прототипа SUP FUN.

## Что теперь действительно находится в архиве

- Flutter/Dart исходники приложения.
- 12 отдельных PNG-экранов визуального концепта SUP FUN.
- Исходный composite-лист со всеми 12 экранами в `assets/images/SUP_FUN_concept_12_screens_full.png`.
- Все изображения подключены через `pubspec.yaml`.
- В приложении добавлен экран «SUP FUN — визуальный концепт» с просмотром 12 экранов и увеличением.
- Основные demo-экраны приложения и навигация из предыдущей версии сохранены.

## Запуск

Открыть папку проекта в Android Studio / VS Code с установленным Flutter SDK и выполнить:

    flutter pub get
    flutter run

Примечание: в текущем рабочем окружении Flutter SDK не установлен, поэтому здесь не заявляется, что APK был локально собран. Архив содержит исходный Flutter-проект и реальные графические assets.
