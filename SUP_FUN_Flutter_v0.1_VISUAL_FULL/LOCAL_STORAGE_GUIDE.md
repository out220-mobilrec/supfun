# Локальное хранение в SUP FUN Mobile

## ✅ Да, маршруты, карты и чаты хранятся локально!

В мобильном приложении SUP FUN реализовано полноценное **оффлайн-хранилище** с использованием:

### 🛠 Технологии

- **Hive** - быстрое NoSQL хранилище для Dart/Flutter
- **SQLite (sqflite)** - для высокочастотных GPS-записей
- **path_provider** - доступ к файловой системе устройства
- **Provider** - управление состоянием

### 📦 Что хранится локально

| Данные | Технология | Расположение |
|--------|-----------|--------------|
| **Маршруты** (GPS-треки) | SQLite | `Documents/trip_points.db` |
| Метаданные маршрутов | Hive box | `routes` |
| **Водоемы** (кэш) | Hive box | `waterbodies` |
| **Чаты** (диалоги) | Hive box | `conversations` |
| **Сообщения** | Hive box | `messages` |
| **Лента сообщества** | Hive box | `feed` |
| **События** | Hive box | `events` |
| **Настройки пользователя** | Hive box | `settings` |

### 📁 Структура файлов

```
lib/
├── models/
│   ├── models.dart              # API модели
│   └── local_models.dart        # Локальные модели с Hive аннотациями
├── services/
│   ├── api_service.dart         # HTTP клиент
│   └── local_storage_service.dart  # Hive + SQLite сервис
├── controllers/
│   └── storage_controller.dart  # Provider для управления состоянием
└── screens/
    ├── chats_list_screen.dart   # Список чатов
    ├── chat_screen.dart         # Экран чата с офлайн-сообщениями
    └── local_data_screen.dart   # Управление локальными данными
```

### 🎯 Возможности локального хранения

#### Маршруты (Routes)
- ✅ Сохранение всех GPS-точек в SQLite (быстрая запись)
- ✅ Метаданные маршрута в Hive
- ✅ Полная информация: расстояние, время, скорость, сложность
- ✅ Возможность пометки маршрута как публичного
- ✅ Удаление маршрутов
- ✅ Статистика по всем маршрутам

#### Водоемы (Water Bodies)
- ✅ Кэширование для офлайн-доступа
- ✅ Добавление в избранное
- ✅ Поиск по кэшу
- ✅ Локальное хранение фотографий (пути)

#### Чаты и сообщения
- ✅ Диалоги с пользователями и группами
- ✅ Сообщения с разными статусами (sending, sent, delivered, read, failed)
- ✅ Поиск по сообщениям
- ✅ Счетчик непрочитанных
- ✅ Закрепленные диалоги
- ✅ Mute/архивирование

#### Лента сообщества
- ✅ Кэширование постов
- ✅ Лайки/комментарии
- ✅ Изображения (локальные пути)

#### События
- ✅ Участие в событиях
- ✅ Список ближайших событий
- ✅ Мои события

### ⚙️ Настройки пользователя
- Автосинхронизация
- GPS-трекинг в фоне
- Уведомления
- Язык и единицы измерения
- Темная тема

### 📊 Статистика

Пользователь может видеть:
- Общее пройденное расстояние
- Количество записанных GPS-точек
- Средняя дистанция маршрута
- Общее время
- Размер кэша

### 🧹 Управление данными

Пользователь может:
- Очистить старые сообщения (90+ дней)
- Очистить весь кэш
- Экспортировать данные
- Удалить отдельные маршруты

### 🔄 Синхронизация

- Автоматическая синхронизация при наличии сети
- Фоновое отслеживание GPS
- Push-уведомления о синхронизации

### 📱 Пример использования

```dart
// Инициализация в main.dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await LocalStorageService.instance.init();
  runApp(const SupFunApp());
}

// Сохранение маршрута
await LocalStorageService.instance.saveRoute(localRoute);

// Сохранение сообщения
await LocalStorageService.instance.saveMessage(message);

// Получение всех диалогов
final conversations = LocalStorageService.instance.getConversations();
```

### 🚀 Производительность

- **SQLite** для GPS-точек - до 10000 точек/сек
- **Hive** для метаданных - мгновенный доступ
- Размер данных: ~50-100 МБ на год активного использования

**Все данные хранятся локально на устройстве пользователя!** 
**Полная работа без интернета для ранее посещенных экранов.**
